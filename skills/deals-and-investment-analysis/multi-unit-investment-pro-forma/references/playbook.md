# Multifamily Pro Forma — detailed procedure

## Reconstruct operating evidence

Match rent-roll date to operating statement periods. Reconcile units, occupied/vacant status, legal rent restrictions, lease expirations, contract rents, concessions, delinquency, actual collections, and other income. Physical occupancy = occupied units / available defined units; economic occupancy = actual rental revenue or collections / defined potential rent for the same period, explicitly stating numerator convention. They measure different things.

Reconcile a trailing-period income statement to the rent roll and ledger. Separate one-time items and normalize only with documented reasons. Treat market-rent comparisons as sourced scenarios; a gap is not immediately attainable rent. Respect lease, local rent, notice, and renovation restrictions. Do not assume every unit can be repriced or vacated at acquisition.

## Current and stabilized NOI

Build current income/losses and operating expenses from the records. Label actual, normalized, and projected columns separately. NOI excludes debt, income tax, depreciation, and capital expenditures; show reserves and capital needs separately. Do not insert per-unit industry expense benchmarks or deem missing expenses zero. Taxes, insurance, utilities, staffing, management, maintenance, and turnover all need property-specific support.

Model stabilization as phased lease-up/renovation with vacancy, tenant protections, rent commencement, concessions, downtime, expenses, and funding. Stable occupancy/rents cannot start before the actual projected work/lease dates. Add capital contingency only with a stated assumption.

## Debt, equity, and distributions

Use actual loan amount, rate convention, amortization/interest-only phases, term, draws, fees, maturities, and refinance assumptions. Reconcile sources/uses including acquisition, repairs, reserves, and all equity contributions. Debt yield = named NOI / loan balance; DSCR uses the relevant named income measure and debt service period. Apply only actual lender criteria.

Build periodic equity cash flows including initial investment, capital calls, operating distributions, net refinancing proceeds, and net sale proceeds. Refinancing proceeds are conditional, not guaranteed distributions. A balloon requires an outstanding-balance and liquidity/refinancing scenario.

Where partnership terms exist, model fees, preferred returns, return of capital, catch-up/promote, and waterfall order only from verified agreement terms. Do not infer an LP/sponsor structure or distribute project-level returns as if they were investor-level returns.

## Exit and returns

For a cap-rate exit, state the income period and whether using forward/stabilized NOI. Exit value = specified NOI / selected cap rate; no cap rate means the value is unresolved. Net sale proceeds = value − selling costs − loan payoff − other established exit obligations. Add released reserves once.

Equity multiple = total cash distributions / total contributed capital, counting returned principal in distributions and excluding retained unrealized equity. IRR uses all complete, dated contributions/distributions; use XIRR or equivalent for irregular timing, and disclose no/multiple-root cases. Do not substitute profit percentage or annualization for IRR. Returns before tax must be labeled.

## Deliverable

Return rent-roll reconciliation; actual/normalized/stabilized income/expense tables; capital and financing schedules; period-by-period equity cash flows; net exit worksheet; clearly defined project/investor returns; user-selected sensitivity matrix for rent, lease-up, cost, debt, or exit cap; and a concise investor brief with assumptions, adverse cases, and open diligence. No unsourced “institutional standard” or guaranteed return.

## Before delivery

Actual and stabilized performance stay separate; lease-up timing respects evidence; capital calls and net exit cash are included; IRR uses dated flows; project returns and investor waterfall returns are not conflated.
