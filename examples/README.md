# Worked examples

These examples use fictional data and hand-authored illustrative outputs. They show what to provide and how to review the result. They are not live model evaluations or promises of identical output.

| Example | Skill | What it demonstrates |
|---|---|---|
| [Listing copy](listing-copy.md) | Listing Content Starter | Staying within verified property facts |
| [Lead prioritization](lead-prioritization.md) | Lead Qualification | Transparent heuristic scores and opt-out handling |
| [Client update](client-update.md) | Transaction Update Starter | A clear next action without invented deadlines |
| [Rental evaluation](rental-evaluation.md) | Rental Property Evaluation | Explicit assumptions and checkable financial calculations |

Never replace a fictional example with private client data in a public contribution. See [the first-use guide](../docs/getting-started.md).
