# RealtySkills v1.0.1

42 free real estate workflows by Evykynn: 12 Starters and 30 Detailed workflows across nine categories, licensed under MIT.

## Changes

- Revised every active workflow around user facts, current evidence, complete task procedures, available tools, and practical chat fallback.
- Removed fixed dates, personal market assumptions, unsupported claims, and automatic legal or financial defaults from active instructions.
- Removed seven legacy copies from current source and downloads; original-source provenance remains in the catalog and Git history.
- Grouped maintainer, branding, promotional, inventory, and publishing records under `docs/maintainer/`.
- Made one complete Markdown guide the beginner route, while preserving supporting playbooks and both workflow levels.
- Derived publication tags and filenames from the catalog version and expanded release workflow triggers to cover skill and packaging updates.

## Download and use

Download `realtyskills-chat-guides-v1.0.1.zip`, extract it, attach one Markdown guide to your AI chat, and describe your task. Detailed guides contain the supporting playbook in the same file.

For skill installation, download an individual `<skill-name>.zip`. For the complete active collection, documentation, useful examples, and build scripts, choose `realtyskills-v1.0.1.zip`. `SHA256SUMS.txt` covers all 44 ZIPs. Each bundle preserves the MIT license notice.

## Verification scope

Packaging checks cover metadata, provenance, internal links, credential patterns, ZIP integrity, and source-byte equality. Worked examples are illustrative; these checks do not establish professional accuracy or live AI-platform compatibility. Review output against current local requirements and supplied evidence.
