# RealtySkills branding

RealtySkills is the final project name. Public author credits and promotional copy use **Evykynn**. The existing `evyevans/realtyskills` repository address and release filenames remain stable.

The README introduction says **I'm Evykynn**. The MIT copyright notice retains its existing legal attribution.

The supplied gold logo is preserved. SVGs change only author name text; embedded image bytes, image positions, and layout are unchanged. PNG pixel changes are confined to the name area, preserving every pixel elsewhere, including the logo.

## Social preview

Open [repository settings](https://github.com/evyevans/realtyskills/settings), then **General → Social preview → Edit → Upload an image**. Select `assets/realtyskills-social-preview.png`.

The PNG is 1280 × 640 and below 1 MB. The README uses the separate wide SVG banner. Sharing platforms may cache older preview images. See [GitHub's social-preview guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
