# RealtySkills v1.0.0

Practical AI skills for real estate professionals, created and maintained by Evy Evans.

- 42 active workflows: 12 starters and 30 detailed playbooks.
- Nine categories organized around real estate tasks.
- Beginner instructions, role recommendations, connected workflows, and fictional examples.
- Standard `SKILL.md` packages with self-contained reference files and MIT licensing.
- Global workflows with explicit labels for US-specific content.

## Choose a download

For AI chat attachments, download `realtyskills-chat-guides-v1.0.0.zip` and choose one Markdown guide. Each guide includes all required instructions.

For installation, download an individual `<skill-name>.zip`. Keep its folder and reference files together. For the entire resource, choose `realtyskills-v1.0.0.zip`.

Checksums for all ZIPs are included in `SHA256SUMS.txt`.

## Verification and limits

Local checks cover metadata, source accounting, internal links, credential patterns, reproducible builds, and archive contents. Worked examples are illustrative, not live model evaluations. Tool availability depends on your product and account. Legal, financial, and jurisdiction-specific content needs current evidence and professional review.

Publication and GitHub Actions status must be verified when this release is created. This document does not claim that those external steps have already occurred.
